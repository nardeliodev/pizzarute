# 📱 Sobre o Projeto

O **PizzaRute** é um aplicativo Android desenvolvido com foco em arquitetura moderna, integração cloud e experiência visual profissional.

O projeto demonstra a integração entre:

- AWS Amplify Auth
- AWS Amplify Storage
- API Gateway
- Amazon S3
- Jetpack Compose
- Arquitetura MVVM

O aplicativo possui:

- Login
- Cadastro
- Cardápio dinâmico
- Upload de comprovantes
- Status de integração
- Interface moderna Material Design 3
